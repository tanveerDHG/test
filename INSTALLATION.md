# WordPress Payment Forms Plugin - Installation & Setup Guide

## Overview

This WordPress plugin allows salespeople to create payment forms with conditional logic, generate payment links, and process client payments. The system includes:

- **Sales Form**: Where salespeople enter client details and invoice information
- **Payment Processing**: Automatic payment link generation 
- **Client Payment**: Secure payment interface for clients
- **Admin Dashboard**: Management and reporting interface
- **Email Notifications**: Automatic confirmation emails

## Installation

### Method 1: Manual Installation

1. **Upload Plugin Files**
   ```
   wp-content/
   └── plugins/
       └── wp-payment-forms/
           ├── wp-payment-forms.php
           ├── includes/
           │   ├── class-payment-forms.php
           │   ├── class-database.php
           │   ├── class-payment-processor.php
           │   └── class-admin.php
           └── assets/
               ├── forms.css
               ├── forms.js
               ├── admin.css
               └── admin.js
   ```

2. **Activate Plugin**
   - Go to WordPress Admin → Plugins
   - Find "WordPress Payment Forms" 
   - Click "Activate"

3. **Database Setup**
   - Plugin automatically creates required database tables on activation
   - Tables: `wp_wpf_sales_forms` and `wp_wpf_transactions`

### Method 2: FTP Upload

1. Upload the entire `wp-payment-forms` folder to `/wp-content/plugins/`
2. Activate the plugin through WordPress Admin

## Initial Setup

### 1. Create Required Pages

#### Sales Page (for salespeople)
- Create a new page: "Create Invoice"
- Add shortcode: `[wpf_sales_form]`
- Publish the page
- Share this URL with your sales team

#### Payment Page (for clients)
- Create a new page: "Payment"
- Set page slug to: `payment`
- Add shortcode: `[wpf_payment_form]`
- Publish the page

### 2. Configure Plugin Settings

Go to **WordPress Admin → Payment Forms → Settings**

- **Default Currency**: Choose your primary currency (USD, EUR, GBP, INR)
- **Email Settings**: Configure sender name and email address
- **Payment Success Message**: Customize the success message
- **Terms & Conditions**: Set your terms and conditions text

### 3. Test the System

1. **Create Test Invoice**:
   - Go to your sales page
   - Fill out the form with test data
   - Submit to generate payment link

2. **Test Payment Process**:
   - Use the generated payment link
   - Complete a test payment
   - Verify email notifications are sent

## Usage Guide

### For Salespeople

1. **Access Sales Form**
   - Navigate to the sales page you created
   - The form includes sections for:
     - Salesperson information
     - Client details
     - Service description
     - Payment amount
     - Terms acceptance

2. **Create Invoice**
   - Fill in all required fields
   - Enter accurate client email (for notifications)
   - Describe the service/product clearly
   - Set the correct amount and currency
   - Accept terms and conditions
   - Click "Generate Payment Link"

3. **Share Payment Link**
   - Payment link is generated immediately
   - Link is also emailed to salesperson
   - Share the link with your client
   - Client can pay using the secure payment interface

### For Clients

1. **Receive Payment Link**
   - Link shared by salesperson via email/message
   - Click the link to access payment page

2. **Review Invoice**
   - See invoice details including:
     - Service description
     - Amount and currency
     - Salesperson contact info

3. **Make Payment**
   - Choose payment method:
     - Credit/Debit Card
     - PayPal
     - Bank Transfer
   - Enter payment details
   - Click "Pay" to complete transaction

4. **Confirmation**
   - Receive instant payment confirmation
   - Confirmation email sent automatically
   - Salesperson also notified of payment

### For Administrators

1. **Dashboard Overview**
   - Go to **WordPress Admin → Payment Forms**
   - View statistics:
     - Total forms created
     - Paid invoices
     - Pending payments
     - Total revenue

2. **Manage Forms**
   - View all form submissions
   - Check payment status
   - Access payment links
   - View detailed form information

3. **Settings Management**
   - Configure default currency
   - Set email templates
   - Customize success messages
   - Update terms and conditions

## Shortcodes

### Sales Form
```
[wpf_sales_form]
```
**Attributes:**
- `title` - Form heading (default: "Create Invoice & Payment Link")
- `currency` - Default currency (default: "USD")

**Example:**
```
[wpf_sales_form title="Generate Client Invoice" currency="EUR"]
```

### Payment Form
```
[wpf_payment_form]
```
This shortcode should be placed on a page with slug "payment" and requires URL parameters (automatically generated by the system).

## Troubleshooting

   - Verify database tables were created

   - Check database permissions
   - Review error logs

## Development

### Extending the Plugin

1. **Add Custom Fields**
```php
// Add to form
add_filter('wpf_form_fields', 'add_custom_fields');

function add_custom_fields($fields) {
    $fields['custom_field'] = array(
        'type' => 'text',
        'label' => 'Custom Field',
        'required' => false
    );
    return $fields;
}
```

2. **Custom Payment Processors**
```php
// Extend payment processor
class Custom_Payment_Processor extends WPF_Payment_Processor {
    public function process_payment($form_id, $payment_data) {
        // Custom payment logic
    }
}
```

3. **Email Customization**
```php
// Customize email templates
add_filter('wpf_email_template', 'custom_email_template', 10, 2);

function custom_email_template($template, $type) {
    if ($type === 'payment_confirmation') {
        // Return custom template
    }
    return $template;
}
```
